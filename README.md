# Argus AML

**Argus AML** is an advanced Anti-Money Laundering (AML) investigation and explainability platform. It combines rule-based financial crime detection, machine learning anomaly detection, dynamic execution planning, and LLM-synthesized investigation summaries to assist compliance analysts.

---

## 🌟 Key Features (Planned)

- **Deterministic & ML Detection**: Rule-based red flag detection alongside isolation forest anomaly scoring.
- **Dynamic Execution Planner**: Adaptively schedules analytical steps based on query intent and entity context.
- **Explainability Engine**: Transparent risk attribution, flag breakdowns, and trace logs for compliance auditing.
- **Interactive Dashboard**: Real-time investigation interface for compliance officers and financial analysts.
